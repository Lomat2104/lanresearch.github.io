# LAN — Research Portfolio

Version 0.1: the empty laboratory.

## Purpose
This is the structural foundation for LAN's independent research portfolio. It deliberately contains no fabricated projects.

## Stack
- HTML
- CSS
- vanilla JavaScript (to be added only when needed)
- GitHub Pages for free hosting

## Planned architecture
- Home — research map / identity
- Investigations — serious independent research
- Laboratory — experiments and prototypes
- Systems — simulations / interactive models
- Field Notes — short research observations
- About — intellectual trajectory

## Next build rule
Do not add portfolio filler. A project enters Investigations only after it has a real question, data, analysis, evidence, interpretation, and reproducible record.
